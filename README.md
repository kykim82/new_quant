# KRW 퀀트 레이더

업비트 원화마켓 전체를 거래대금과 유의 종목 여부로 먼저 선별하고, 상위 9개 유동성 종목의 완성된 15분·1시간·4시간봉과 호가를 분석하는 추천 전용 웹 대시보드입니다. 15분 단타와 1~4시간 스윙 후보를 분리해 매수 구간, 대표 매수가, 손절가, 1차·2차·3차 매도가를 표시합니다.

이 프로그램은 주문을 실행하지 않으며 수익을 보장하지 않습니다. 실제 주문 전에는 최신 가격, 공시, 본인의 손실 감내 범위를 별도로 확인해야 합니다.

## 분석 기준

- 공통 필터는 유의·주의 종목, 24시간 거래대금, 100만원 가상 주문의 호가 스프레드와 슬리피지, 최근 결측 봉, BTC 시장 국면을 확인합니다.
- 15분 단타는 1시간·15분 EMA 20/50 상승 배열, 20봉 Donchian 고점 돌파, RVOL 1.5배 이상, RSI 55~70, ATR 추격 제한을 사용합니다.
- 1~4시간 스윙은 4시간 EMA 20/50/200 정배열, EMA 50 상승, ADX/DMI 추세, RSI, 1시간 돌파 또는 눌림 회복을 사용합니다.
- 보조 점수에는 PPO, CMF, BTC 대비 상대강도, 거래대금, 호가 품질을 반영합니다.
- 가격 계획은 최근 확정 피벗과 ATR로 손절을 정하고, 대표 매수가 대비 1R·2R·3R을 목표가로 계산합니다.
- 업비트의 가격 구간별 KRW 호가 단위, 편도 수수료 0.05%, 예상 슬리피지를 반영합니다.
- 단타 70점, 스윙 72점 이상만 전략별 최대 3개까지 보여줍니다. 조건을 통과하지 못하면 추천 없음이 정상 결과입니다.

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```powershell
cd D:\kywork\New_quant
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 업비트 공개 시세만 사용하므로 API 키는 필요하지 않습니다.

검증 명령은 다음과 같습니다.

```powershell
npm run typecheck
npm test
npm run lint
npm run build
```

## 데이터와 배포

- 비공개 배포 주소는 `https://krw-quant-radar.kykim82.chatgpt.site`입니다.
- Cloudflare Worker가 업비트 API를 서버에서 호출하므로 브라우저의 호출 제한과 CORS 문제를 피합니다.
- D1에는 최신 분석 결과와 최근 96회 결과를 저장합니다.
- 예약 분석은 매 15분봉 마감 1분 뒤에 실행됩니다.
- 화면은 1분마다 최신 D1 결과를 확인하고, 탭으로 돌아왔을 때 즉시 다시 확인합니다.
- 배포는 `.openai/hosting.json`에 연결된 소유자 전용 비공개 Cloudflare Sites 프로젝트를 사용합니다.
