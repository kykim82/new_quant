# KRW 퀀트 레이더

업비트 원화마켓에서 주의·경고 종목을 제외한 전체를 순회 분석하는 추천 전용 웹 대시보드입니다. 15분 단타와 1~4시간 스윙 후보의 매수 구간·손절가·1~3차 매도가, 관찰·대기 종목의 미충족 사유를 구분해 표시합니다. 거래대금이 작은 종목도 수집하며 최초 전체 준비는 여러 실행에 걸칩니다.

이 프로그램은 주문을 실행하지 않으며 수익을 보장하지 않습니다. 실제 주문 전에는 최신 가격, 공시, 본인의 손실 감내 범위를 별도로 확인해야 합니다.

## 분석 기준

- 공통 필터는 유의·주의 종목, 24시간 거래대금, 100만원 가상 주문의 호가 스프레드와 슬리피지, 최근 결측 봉, BTC 시장 국면을 확인합니다.
- 진입 후보의 24시간 거래대금 하한은 단타 10억·스윙 5억 원입니다. 이 값은 검증할 초기 설정이며 최적값을 의미하지 않습니다.
- 단타는 1시간·15분 EMA20/50 상승 배열과 돌파 또는 EMA20 눌림 후 직전 고가 회복을 확인합니다. 돌파 RVOL 1.2배, 눌림 0.8배 이상과 RSI 45~78을 사용하고 RSI 적정도·거래대금 강도는 점수에도 반영합니다.
- 스윙은 4시간 EMA20 > EMA50, 종가 > EMA50, EMA50 상승, ADX ≥ 15와 +DI > -DI, RSI 45 이상 78 미만을 요구합니다. EMA50 > EMA200과 강한 ADX는 가점이며 1시간 돌파 또는 눌림 회복 신호는 필수입니다.
- 보조 점수에는 PPO, CMF, BTC 대비 상대강도, 거래대금, 호가 품질을 반영합니다.
- 가격 계획은 최근 확정 피벗과 ATR로 손절을 정하고, 대표 매수가 대비 1R·2R·3R을 목표가로 계산합니다.
- 업비트의 가격 구간별 KRW 호가 단위, 편도 수수료 0.05%, 예상 슬리피지를 반영합니다.
- 단타 70점, 스윙 72점 이상만 전략별 최대 10개까지 보여줍니다. 이전 3일 일평균 대비 24시간 거래대금 증가도 가점에 반영합니다. 관찰 목록은 매수 추천이 아닙니다.
- 분석 후 20분이 지났거나 현재가·현재 거래대금·현재 호가 조건이 맞지 않는 저장 후보는 진입 목록에서 제외합니다. 전체 응답이 3분 이상 지연되면 매수 후보를 숨깁니다.

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```powershell
cd D:\kywork\New_quant
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 업비트 공개 시세만 사용하므로 API 키는 필요하지 않습니다.

검증 명령은 다음과 같습니다.

```powershell
npm run typecheck
npm test
npm run lint
npm run build
```

## 데이터와 배포

- 운영 주소는 사용자 Cloudflare 계정의 `https://new-quant.kykim82.workers.dev`입니다.
- Cloudflare Worker가 업비트 API를 서버에서 호출하므로 브라우저의 호출 제한과 CORS 문제를 피합니다.
- D1에는 종목별 캔들·분석 시각·미충족 사유와 최근 96회 대시보드, 기존/개선 전략 모의 기록을 저장합니다. 새 테이블과 인덱스는 처음 갱신할 때 자동 생성됩니다.
- 예약 분석은 매분 실행됩니다. 실행당 캔들 호출 40회, 전체 외부 요청 최대 45회 안에서 가장 오래전에 확인한 종목부터 처리합니다. 초기 준비는 약 30분 이상 걸릴 수 있고 이후에는 시간대별 캐시를 재사용합니다. 실패·이력 부족·지연은 별도로 표시하며 15분 이내 전종목 갱신을 보장하지 않습니다.
- 화면은 1분마다 최신 D1 결과를 확인하고, 탭으로 돌아왔을 때 즉시 다시 확인합니다.
- GitHub `kykim82/new_quant`의 main 브랜치로 푸시하면 사용자 Cloudflare Workers Builds가 자동 배포합니다. 빌드 명령은 `npm run build`, 배포 명령은 `npx wrangler deploy`입니다. 생성 설정은 `dist/server/wrangler.json`입니다.
- 기존 전략 병행 비교는 같은 전체시장 데이터를 사용하며 과거 9종목 제한을 재현한 백테스트가 아닙니다. 모의 기록은 매수가 접촉 이후 1/3씩 분할 청산하고 수수료·가정 슬리피지를 반영합니다. 동일 봉 순서 불명확과 데이터 누락은 평균 수익률에서 제외하므로 실제 수익률로 해석하지 않아야 합니다.
