# 매수·목표가 산정 엔진 검토 계획

- 범위. 사용자 제공 Supertrend 및 Target Trend Pine 소스를 분석하고, 기존 Python 첨부 및 운영 전략과 비교한다. 운영 코드·GitHub·Cloudflare는 변경하지 않는다.
- 전제. 제공 소스의 기본 입력값으로 분석한다. 사용자의 TradingView 실제 입력값과 차트 거래소·시간대는 아직 확인하지 않았다.
- 방법. 원본 수식·상태 유지·완성 봉·ATR 초기화를 확인하고 공식 TradingView 문서로 피벗·피보나치·실시간 동작을 대조한다.
- 설계. 추세 판단, 진입, 구조적 무효화 가격, 저항 후보 생성·중복 병합·목표 선택을 분리한다. 손절폭 배수는 목표가 생성에 쓰지 않는다.
- 검증. 원본 일치 검사와 개선 전략 성과 검증을 구분한다. 시점별 데이터만 쓰는 순차검증, 진입 이후 성과, 비용·미체결·동일봉 모호성 등을 명시한다.
- 산출물. review.md, checklist.md, context-notes.md를 포함하는 로컬 검토 문서. 적용 전 설계 결정을 사용자에게 설명한다.
