## 2. Target Trend 원본의 정확한 의미

기본 Trend Length는10, Set Targets는0이다. 다음에서 W는 Wilder 방식 ATR200을 다시200개 단순평균한 값이며 V=0.8W이다.

```text
W(t) = SMA(ATR_Wilder(200), 200)
V(t) = 0.8 × W(t)
상단(t) = SMA(고가, 10) + V(t)
하단(t) = SMA(저가, 10) − V(t)
```

종가가 상단을 상향 교차하면 상승 상태, 하단을 하향 교차하면 하락 상태로 바뀐다. 원본은 `barstate.isconfirmed`로 완성 봉에서만 상태를 갱신한다. 단순히 상단보다 높다는 조건이 아니라 이전 봉과 현재 봉의 교차 관계를 사용한다. 초기 na 상태와 실제 하락→상승 전환도 구분해야 한다. 관련 원본은23~46행이다.

실제 상승 전환 신호 s에서 다음 가격의 수평선을 생성한다.

```text
E = close(s)
S = 하단(s)
T1 = E + V(s) × (5 + target)
T2 = E + V(s) × (10 + 2 × target)
T3 = E + V(s) × (15 + 3 × target)
```

기본 target=0일 때 목표는 E+4W, E+8W, E+12W이다. **여기서 W는 짧은 ATR14나 ATR21이 아니다.** target 입력이 바뀌면 세 목표 간격도 함께 달라진다.

### 목표 고정과 동적 추세선의 구분

- 신호 생성 당시 매수·손절·목표 선의 가격은 고정된다. 이후 선의 x좌표만 연장하며, 반대 신호에서는 해당 방향의 선을 지운다. 원본80~98,165~168행.
- 배경에 그려지는 `trend_value`는 최신 상단/하단이다. 따라서 동적 추세선과 신호 당시 고정 손절선은 서로 다를 수 있다.
- 체크 표시는 해당 봉의 고저 범위가 목표선을 포함했다는 표시다. 실제 진입 체결, 수수료, 분할 비중, 동일봉 손절/목표 순서를 검증한 수익 기록이 아니다.
- 최소 약399개 유효 봉이 있어야 W의 첫 계산값이 나온다. 교차 판단과 유효 신호 형성에는 추가 이력이 필요하고, 초기 상태 및 Wilder 수렴 문제 때문에399개만으로 TradingView 전체 이력과 동일하다고 단정할 수 없다.

## 3. Supertrend 원본의 역할과 주의점

기본값은 ATR기간10, 배수3, 기준가격hl2이다. `changeATR=true`에서는 Wilder ATR, false에서는 TR의 단순평균을 사용한다.

```text
기본 하단 = (고가+저가)/2 − 3 × ATR10
기본 상단 = (고가+저가)/2 + 3 × ATR10
```

이전 종가와 이전 밴드의 관계에 따라 하단을 올리거나 상단을 내리는 상태 유지 규칙을 적용한다. 하락 중 현재 종가가 이전 상단을 넘으면 상승 전환, 상승 중 이전 하단 밑으로 내려가면 하락 전환이다. 원본12~20행.

Supertrend는 추세 확인·추적 청산에 적합한 후보이지, 위쪽의1~3차 저항가를 직접 계산하는 지표는 아니다. 첨부에는 `barstate.isconfirmed`가 없어 실시간 봉에서는 표시 신호가 바뀔 수 있다. 프로그램 추천은 완성 봉으로 제한하고, 즉시 가격 손절과 종가 기준 추세 청산은 별개로 표시한다. TradingView도 완성 봉 조건이 실시간 신호 변화를 줄이는 방법임을 설명한다. [Bar states](https://www.tradingview.com/pine-script-docs/concepts/bar-states/)

TradingView 내장 Supertrend나 임의 라이브러리가 이 첨부와 초기 방향·밴드 비교·ATR 시드까지 동일하다고 가정하지 않는다. 원본 일치 모드에서는 첨부 수식을 기준으로 한다. 일반 역할 설명은 [TradingView Supertrend](https://www.tradingview.com/support/solutions/43000634738-supertrend/)를 참조했다.

## 4. 통합할 지표와 제한할 지표

| 정보 종류 | 초기 채택 | 역할 및 중복 제한 |
|---|---|---|
| 추세 | Supertrend, 기존 EMA | 상위 봉 방향·진입 가능 상태. ST와EMA를 독립 확률처럼 합산하지 않음 |
| 실제 가격 구조 | 확정 스윙 고점·저점, 전일·전주 고저 | 진입 지지와 가장 가까운 저항. 같은 고점을20봉/50봉/스윙으로 중복 가산하지 않음 |
| 기간 기준 | Traditional Pivot P,R1~R3,S1~S3 | 전일 또는 전주가 완료된 이후의 고정 기준 가격 |
| 파동 투영 | ABC 피보나치 확장 | 확인된 상승파와 눌림이 있을 때만 다음 목표 후보 생성 |
| 변동성 투영 | 원본 Target Trend | 실거래 저항이 아닌 확장 목표 후보와 도달 거리 비교 |
| 거래 참여 | 기존 RVOL, 선택적 Anchored VWAP | 신호 거래량·눌림 회복 확인. 목표 세 개를 직접 생성하는 용도 아님 |

RSI·MACD·Stochastic을 모두 '독립 찬성표'로 추가하지 않는다. 볼린저·켈트너·ATR채널·Target Trend도 변동성 정보가 겹치므로 전부 목표 후보로 증식시키지 않는다. 초기에는 Traditional Pivot 한 종류만 사용하고 Camarilla·Woodie·Fibonacci Pivot은 별도 비교 실험으로 남긴다.

실제 가격대별 거래량인 Volume Profile의 POC/VAH는 향후 유용한 후보지만, 현재15분OHLCV만으로 정밀 매물대를 복원했다고 표시하지 않는다. TradingView도 하위 시간대 데이터를 이용한다. 데이터 수집·저장 비용이 필요한2단계 기능이다. [Volume Profile 계산](https://www.tradingview.com/support/solutions/43000502040-volume-profile-indicators-basic-concepts/)

AVWAP를 추가할 경우 확정된 파동 시작 또는 신호 시점을 기준점으로 기록한다. 원화 누적 거래대금/누적 코인 거래량으로 계산하면 캔들HLC3×거래량 방식과 다른 값이므로, TradingView 기본 소스와의 차이를 명시한다. [Anchored VWAP](https://www.tradingview.com/support/solutions/43000669764-anchored-vwap-drawing-tool/)

## 5. 매수·손절·목표가 산정 절차

### A. 시점과 전략 분리

- 단타는15분 진입과1시간 추세·저항, 전일 피벗을 주로 사용한다.4시간 저항은 위쪽 장벽으로 추가 확인한다.
- 스윙은1시간 진입과4시간 추세·저항, 전일·전주 피벗을 사용한다.
- 모든 상위 봉은 해당 시점에 마감된 봉만 사용한다. 하루는 업비트 일봉의UTC00:00,한국09:00 기준으로 맞춘다. 주봉은 거래소 캔들 기준을 확인해 사용하고 로컬 자정으로 임의 집계하지 않는다. [업비트 일봉 예시](https://docs.upbit.com/kr/kr/docs/first-quotation-api-call)
- 단타는 수시간, 스윙은 수일이라는 보유 평가 기간을 별도로 명시한다. 정확한 시간 상한은 기존6시간/72시간과 비교 검증한 후 확정한다.15분봉 신호라는 이유만으로15분 안에 목표에 도달한다고 해석하지 않는다.

### B. 진입은 현재 유효한 두 가지 구조로 제한

1. 돌파·재확인형. 완성 봉이 확정 저항 위로 올라가고 거래량이 동반된 뒤, 해당 구간이 지지로 유지되는지 확인한다. 그 지지 구간을 진입 후보로 삼는다.
2. 눌림 회복형. 상위 추세가 유지되는 동안 확정 저점·전환 지지·필요시AVWAP 근처에서 하락이 멈추고 다시 상승하는 완성 봉을 확인한다.

Target Trend의 과거 신호 종가를 현재 매수가로 그대로 복사하지 않는다. 신호 당시 가격과 지금 가능한 진입 구간을 별도 표시한다. 중간값은 구간의 대표값일 뿐 체결 보장이 아니다. 추격으로 구간을 벗어나면 만료하거나 대기시킨다. 체결 이후 실제 평균 매수가가 생기면 수익률만 실제 기준으로 다시 계산한다.

### C. 손절은 구조 무효화 가격에서 독립 산정

돌파형은 재확인 지지의 하단, 눌림형은 신호를 지탱한 확정 저점 아래에 변동성·호가 단위 완충을 둔다. 완충계수는 초기 가설로 비교 검증하며, 손절을 가까이 붙여 손익비를 인위적으로 좋게 만들지 않는다. 구조상 필요한 손절이 사용자의 위험 한도보다 크면 종목을 제외하거나 주문금액을 줄이는 판단이지 손절선을 억지로 올릴 문제가 아니다.

Supertrend 추적 청산은 별도 상태로 계산한다. 롱 포지션의 추적 보호선은 원칙적으로 올릴 수만 있고, 초기 손절을 느슨하게 내리지 않는다. 장중 보호 가격 이탈과 완성 봉 추세 전환 청산은 구분한다. 자동주문은 이번 서비스 범위에 포함하지 않는다.

### D. 위쪽 가격 후보를 생성

**가격 구조.** 현재 진입가 위의 확정 스윙 고점, 전일·전주 고점을 모은다. '과거에 확인된 가격'이라는 뜻이지 미래 저항 작용의 보장은 아니다. 피벗 저점/고점은 오른쪽 확인 봉이 모두 닫힌 시점부터만 사용할 수 있다. 미래에 확정될 고점을 과거 시점에 알고 있었다고 취급하지 않는다. [TradingView 피벗 표시 주의](https://www.tradingview.com/pine-script-docs/concepts/repainting/)

**Traditional Pivot.** 완료된 이전 기간의 H,L,C로 계산한다.

```text
P = (H+L+C)/3
R1 = 2P−L
R2 = P+(H−L)
R3 = H+2(P−L)
```

이 방식은 국소 스윙 고점/저점을 뜻하는 '피벗'과 다른 개념이다. 여러 피벗 종류의 숫자를 동시에 늘리지 않는다. [TradingView Pivot Points Standard](https://www.tradingview.com/support/solutions/43000521824-pivot-points-standard/)

**ABC 피보나치 확장.** 시간순으로 확정된 저점A→고점B→눌림 저점C를 선택한다. 롱 초기안은 B>A, A<C<B인 상승 구조이며, 같은 기준의 최근 유효 파동 하나를 시간대별로 선택한다. 피벗 확인 지연과 최소 파동 크기·유효 기간을 사전에 정한다. 표시가 유리하도록 사후에A/B/C를 바꾸지 않는다.

```text
F(r) = C + (B−A) × r
r 후보 = 1.0, 1.272, 1.618
```

진입가 아래의 결과는 목표에서 제외한다. A/B/C가 확인되지 않으면 피보나치 목표를 만들지 않는다. 로그 스케일 확장과 위 선형 계산은 다르므로 초기안은 선형으로 명시한다. [TradingView 3점 확장 설명](https://www.tradingview.com/support/solutions/43000518137-trend-based-fib-extension-drawing-tool/)

**Target Trend.** 원본 신호 시점의T1/T2/T3 중 지금 진입가 위에 있고 유효한 계획에 속한 값을 '변동성 확장 목표'로 넣는다. 실제 고점 저항과 같은 종류의 증거로 취급하지 않는다. 기존TT신호가 너무 오래됐으면 새 진입 신호의 ATR 목표를 별도 '변형 모델'로 계산할 수 있으나 원본 일치 값인 것처럼 표시하지 않는다.

### E. 가까운 가격 후보를 저항 구간으로 병합

- 각 후보에 가격,종류,시간대,기준봉,확정시각,계산 시점,원본 식별자를 기록한다.
- 진입가 위의 후보를 정렬하고 가격 간격이 작은 후보들을 하나의 구간으로 묶는다. 초기 허용폭은 `max(2호가,진입 시간대 ATR14의0.15배)`를 검증 대상으로 제안한다. 최적값으로 주장하지 않는다.
- 단순 연결 방식으로 구간 폭이 계속 커지지 않도록 구간 전체 폭에 같은 제한을 둔다. 과도하게 넓은 구간은 분리한다.
- 동일 고점의 재표현은 한 근거로 센다. 피보나치와같은 OHLC 파생값이 여러 개 겹친다고 통계적 독립 확인 횟수로 해석하지 않는다.
- 초기에는 임의의 승률 점수보다 '가격 구조 있음 / 기간 피벗 / 파동 투영 / 변동성 투영' 근거와 상위 봉 여부를 보여준다. 서로 다른 종류가 겹친 구간을 우선 검토하되, 더 높은 점수의 먼 구간을 택하려고 앞의 유의미한 저항을 건너뛰지 않는다.

### F. 가까운 유효 구간부터1~3차 목표 선택

- 1차는 가장 가까운 유의미한 저항 구간,2차는 그 다음 구간,3차는 그 다음 저항 또는 명확히 구분한 추세 확장 구간이다.
- 매도 가격은 저항 구간의 아래쪽에서 한 호가 앞선 값을 초기안으로 쓰고, 가격대 변경 후 호가 단위·순서·간격을 재검사한다. 역시 체결 보장은 아니다.
- 투영값밖에 없으면 '예상 확장 목표'로 표시하고, 확인된 저항인 것처럼 안내하지 않는다. 근거가 부족한3차 목표는 '산정 대기'로 둘 수 있다. 세 칸을 채우기 위한1/2/3R 대체는 하지 않는다.
- 인접 저항이 너무 가까워 비용 후 여력이 작으면 '상승 여력 부족'이다. 가까운 저항을 생략하고 먼5% 목표를 골라 추천하지 않는다.
- 가격 계획은 발행 시점에 고정하고 ID·만료시각을 저장한다. 새 목표가 필요하면 이전 계획을 조용히 덮지 않고 새 버전과 변경 이유를 남긴다.

### G. 수익 여력과 비용 표시

표시값은 실제 도달 확률을 곱한 '기대수익'이 아니라 목표까지의 수익 여력이다. 세 목표 각각의 비용 전·후 수익률과 정해진 분할 비중의 전부 체결 시 수익률을 구분한다. 순이익은 매수 비용을 더하고 각 매도 대금에서 수수료·그 시나리오의 체결 비용을 뺀다. 지정가 미체결, 시장가 매도 호가 부족, 손절 시 미끄러짐을 구분하고, 현재 매수 슬리피지를 미래 매도 비용의 확정값처럼 사용하지 않는다.

스프레드는 사용자 요청대로 주의 표시만 유지한다. 최소 비용 후 수익 여력 기준은 별도로 정할 수 있지만, 기존 대화의5%가3차 목표 기준인지 분할 전량 청산 기준인지는 미확정이다. 이번 설계에서5%를 임의로 강제하지 않는다. 손익비는 목표를 생성하거나 후보의 주요 점수를 만드는 용도가 아닌 별도 위험 참고값으로 둔다.

다음은 실제 종목 데이터가 아닌 설명용 가정이다. 매수1,000원, 지지 무효화 가격965원, 위쪽 구간 하단이1,040/1,080/1,130원이고 호가 단위가1원이라고 가정한다.

## 7. 적용 전에 필요한 기술 보완

1. 현재15분·1시간 캔들200개,4시간400개 저장으로는 원본Target Trend를 안정적으로 재현할 수 없다. 초기 이력을 단계적으로 늘리고 ATR/SMA·추세 상태·신호 가격을 영속화해야 한다.800~1,200개 시작 이력은 검증 후보이며 특정 개수만으로 일치를 보장하지 않는다.
2. 시작 이력과결측 봉 처리도 TradingView와 맞춰야 한다. 현재 프로그램은 무거래 구간을 합성 봉으로 채운다. 공급자가 생략한 봉과 합성 봉은 이동평균·ATR 기간 의미가 다를 수 있다. 원본 대조는 같은OHLC와같은 시작 시점으로 우선 수행한다.
3. 전일·전주 피벗용 완료된 일봉/주봉과 확인된 스윙 고점 정보가 추가로 필요하다. 기간이 부족한 신규 상장 종목에 가짜 초기값을 만들지 않는다.
4. 현재 실행별 캔들 호출 예산40과 분할 순회 구조를 보존한다. 이력 증가로 최초 준비 시간이 늘어남을 표시하고, 후보 재평가 지연이 단타 유효기간보다 길어지지 않는지 측정한다. 목표 계산 개선보다 데이터 지연이 더 큰 문제가 될 수 있다.
5. 목표 데이터는 단순숫자3개에서 근거·구간·시점·투영 여부·비용 후 수익 여력·산정불가 상태를 담는 구조로 확장한다. 차트와 카드,모의 추적도 같은 계획ID를 사용한다.

## 8. 정확성 검증과 성과 검증은 별개

### 계산 일치 검사

- 같은 거래소·종목·표준캔들·시간대·입력값·가격 데이터·시작 이력에서 원본의 ATR,밴드,방향,전환시각,고정 목표를 비교한다.
- Supertrend의 ATR방식 선택,이전 밴드 참조,같은 값 경계,초기 방향을 검사한다.
- Target Trend의 최소이력,na초기상태,교차조건,완성 봉,Set Targets 변경,목표 고정,반대 신호 종료를 검사한다.
- 신호 후 가격이 목표에 닿기만 한 것과 실제 매수 후 청산을 구분한다.

### 통합 엔진 검사

- 미래 봉을 추가해도 과거에 이미 발행한 계획이 변하지 않는지 검사한다.
- 피벗은 발생 봉이 아니라 확인 가능 시점부터 사용하고,ABC 선택도 그 시점의확정정보만 사용한다.
- 동일 고점 중복 제거,동점·유사 구간의 결정적 병합,직전 저항 생략 방지,가격대별 호가 단위,부족한 목표 처리 등을 검사한다.
- 손절값만 바꿔도 저항 후보 기반 목표가가 따라서1/2/3배로 변하지 않는지 검사한다.
- 경고 종목·오래된 시세·합성 구간·데이터 누락·신호 만료 처리를 검사한다.

### 성과 비교

- 비교군A는 현재1/2/3R, B는 원본TT고정목표, C는 구조+Traditional Pivot, D는C+피보나치/TT투영이다. 진입·보유기간·비용·분할비중을 같게 유지해 목표 계산의 효과를 먼저 분리한다. 진입 변경 효과는 그다음 비교한다.
- 시간순 학습/선정 구간과 평가 구간을 분리하고,상승·하락·횡보 구간에서 비교한다. 평가에 쓴 미래구간으로 임계값을 재조정하지 않는다.
- 미래고점 도달률만으로 우위를 판단하지 않는다. 실제 진입 가능한 신호 수,순평균손익,손실 꼬리,최대낙폭,보유시간,목표별 도달률,신호 신선도를 함께 본다.
- 추천 이후 체결부터 추적하고,동일봉 목표/손절은1분 데이터로 확인하거나 불명확/보수적 결과로 병기한다. 불명확 거래를 모두 빼서 성과를 부풀리지 않는다.
- 당시 상장·주의 상태 이력이 없으면 현재종목만의생존편향이 있는 평가로 명시한다. 신규상장·거래정지·거래대금 하위 종목을사후에임의제거하지 않는다.
- 단타 목표를 의도한 보유시간 안에서 달성했는지 확인한다. 더 먼 목표를 찍는 것만으로 기존보다 좋아졌다고 결론내리지 않는다.
