# 가격 산정 검토 결정 기록

- 이번 요청은 검토와 설계이다. 코드 적용·외부 업로드·배포를 수행하지 않는다.
- 검토일은2026-09-06이다. 문서는 실제 프로젝트의 reviews/price-engine-design에 보관하고 로컬 문서 커밋만 수행한다. 운영 소스ZIP과 원격 저장소는 갱신하지 않는다.
- Supertrend 첨부 기본값은 ATR10,배수3,기준hl2,Wilder ATR 선택이다. 별도 barstate.isconfirmed 조건이 없다.
- Target Trend 첨부 기본값은 Trend Length10,Set Targets0이다. 변동폭은 SMA(ATR200,200)×0.8이며 상승/하락 상태는 완성 봉에서만 갱신된다.
- Target Trend는 신호 발생 시 entry/stop/target 선의 가격을 고정하고 이후 선의 가로 위치만 연장한다. 앞서 분석한 quant-terminal Python의 최신 ATR 목표 재계산과 다르다.
- 첨부 Target Trend 헤더는 BigBeluga의 CC BY-NC-SA4.0이다. 원본 코드 이식과 일반 지표 수식 기반 독립 구현을 구분하고 배포 전 이용 조건 확인이 필요하다.
- 최종안은 구조 고점→기간 피벗→ABC 확장→TT 변동성 투영의 근거를 가격 구간별로 병합한다. 같은 고점의 중복 표를 제거하고 앞의 저항을 생략하지 않는다. 미확정3차 목표는 산정 대기로 둔다.
- 원본기본목표 E1000,W10→1040/1080/1120,Traditional R3의 두 동치식,설명용 목표1039/1079/1129의 수익률3.9/7.9/12.9%를 산술 확인했다. 이는 TradingView 수치 일치나 성과 테스트가 아니다.
- 코드 변경이 없으므로 기존42개 프로그램 테스트를 이번 설계의 검증 결과로 재사용하지 않는다. 원본 일치·미래정보 금지·시간순 성과 검증 기준을 review.md에 명시했다.
